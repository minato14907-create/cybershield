เกี่ยวกับโปรเจคนี้

CyberShield เป็นโปรเจค Portfolio ด้าน Cybersecurity ที่สร้างขึ้นเพื่อแสดงทักษะจริงทางด้าน ความปลอดภัยเครือข่าย, การเข้ารหัสข้อมูล และ Ethical Haking พัฒนาขึ้นสำหรับการสมัครเข้าศึกษาต่อ สาขาวิศวกรรมคอมพิวเตอร์ (CEDT) จุฬาลงกรณ์มหาวิทยาลัย

ทักษะที่แสดง

Python Network Security Cryptography Flask HTML/CSS/JS Socket Programming Packet Analysis Hash Algorithms Ethical Hacking

เครื่องมือที่มี

► Port Scanner - สแกนพอร์ต TCP หลาย threads พร้อม grab banner
► Packet Analyzer - จับและวิเคราะห์ทราฟิกเครือข่าย
► Password Analyzer - วิเคราะห์ความแรงพร้อมคำนวณ entropy
► Encryption Suite - อัลกอริทึมเข้ารหัสทั้งแบบคลาสสิกและสมัยใหม่
► Subdomain Scanner - สแกน subdomain ด้วย async
► Hash Cracker - สาธิต dictionary attack และ brute force
